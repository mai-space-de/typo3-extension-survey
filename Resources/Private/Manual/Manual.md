# Handbuch: Umfragen

Eine Umfrage hat Titel, Einleitung und Fragen. Nur aktive Umfragen können ausgefüllt werden. Ergebnisse siehst du im Modul **Survey results** unter **Web**.

## Fragen

| Typ | Eingabe |
|---|---|
| Einzelauswahl | eine Option |
| Mehrfachauswahl | mehrere Optionen |
| Texteingabe | freier Text |
| Skala | Wert zwischen Minimum und Maximum |
| Datum | ein Datum |

Pflichtfragen müssen beantwortet sein. Die Reihenfolge ziehst du an der Frage.

## Auf der Seite

Das Inhaltselement verweist auf genau eine Umfrage. Anonyme Teilnahme und ein Schutz vor doppeltem Absenden sind Schalter an der Umfrage.

Die Dankesmeldung steht im Feld für die Erfolgsmeldung. Exporte der Antworten liegen im Ergebnis-Modul.
